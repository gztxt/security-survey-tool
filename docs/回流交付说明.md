# 回流交付说明（本地镜像 → NAS）

> 依据《架构设计-安防勘点工具收敛》决策 8 定稿。本次收敛重构（T1–T5）在本地 git 镜像仓完成，
> 通过"仅改动文件"的回传包覆盖 NAS 源，NAS 全量数据不做任何物理删除。

## 0. 影响范围声明

- 回传包只含**源码层改动文件**（`git diff --name-only baseline-pre-refactor HEAD` 产物）。
- **绝不包含**：`node_modules/`、`dist/`、`dist-electron/`、`release/`、`resources/oda/`、
  任何用户 `.survey` 项目文件（用户数据存于 `app.getPath('userData')`，与仓库无关）。
- `.bak-*` / `__pycache__` 的"删除"以 **git mv 至 `_archive/pre-refactor-20260911/`** 表达，
  内容零丢失；NAS 端 tar 覆盖不会删旧位置，需执行 `scripts/apply-archive-list.sh` 补归档。

## 1. 本地（已完成）


## 2. 产出回传包（T5 步骤收口）

```bash
BASE=$(git rev-parse baseline-pre-refactor)
git diff --name-only $BASE HEAD > /tmp/changed.txt
mkdir -p deliverables
git archive --format=tar -o deliverables/changes.tar HEAD $(cat /tmp/changed.txt)
# changes-manifest.txt：每文件路径 + sha256 + 所属任务号 + 新增/修改
```

## 3. NAS 侧（人工执行）

```bash
cd /fs/1000/ftp/技术文档
cp -a 安防勘点工具 安防勘点工具.bak-$(date +%Y%m%d_%H%M%S)   # 全量备份
cd 安防勘点工具
[ -d .git ] || { git init -b master && git add -A && git commit -m "baseline from NAS"; }
tar -xf /path/changes.tar -C .                # 只覆盖改动过的源码文件
bash scripts/apply-archive-list.sh            # 按 MANIFEST 把 .bak/pyc 补移到 _archive/
rm -rf node_modules dist dist-electron        # 可选：NAS 端重新 pnpm install
# 不碰：releases/、resources/oda/、任何用户 .survey 文件
```

> `安防勘点工具/` 目录整体**不可移动、不可改名**（cron/agent 有引用面）；
> `git init` 只在其内部创建 `.git`，安全。

## 4. 回滚（两级）

```bash

# 重：整目录还原

```

## 5. 验证闸门

回传前本地必须全绿（`powershell -File scripts/verify.ps1`，退出码 0）：
install → packages build → vue-tsc --noEmit → vitest（4 包含 dxf 往返测试）→ build:app。
若环境受限跑不了某些闸门，交付说明中必须如实标注"验证缺失项"，不得谎报通过。

### 5.1 本次验证结论（T5 收口）

- **已全绿（本地实测）**：`vue-tsc --noEmit`（exit 0）、`vitest`（desktop 15 绿 + exporter 16 绿）、
  `vite build`（renderer + main + preload 三产物齐全，pdfjs worker 资源 `pdf.worker.min-*.mjs` 正常产出）。
- **vite.config.ts 已改动（须记入清单）**：新增 `build.target: 'es2022'`。
  原因：pdfjs-dist 的 `pdf.worker.min.mjs` 含顶层 await，默认目标 chrome87/es2020 会在 esbuild 阶段报
  "Top-level await is not available"。Electron 28 内嵌 Chromium 120 原生支持 ES2022，提升目标安全。
- **验证缺失项（如实声明，需人工冒烟）**：以下行为依赖 Electron 实机，本地无法自动化验证，回传后须执行
  一次"新手主流程冒烟"（PRD §1 唯一验收目标）：
  1. 拖入/选择 `.png`/`.jpg` → 画布出现位图底图，缩放平移与标注层同步；
  2. 选择多页 `.pdf` → 出现选页对话框（默认首页），渲染清晰（scale=2）；
  3. `BASEMAP` 图层不可被框选/点选误操作，可在图层面板整体隐藏（AC-1.4）；
  4. 保存后 `.survey` 体积不随底图暴涨（dataURL 已剥离）；关闭重开 → 底图仍在（重水合）；
     原图改名后重开 → 出现"底图文件已移动"提示且标注不丢；
  5. 点位图 PNG/PDF 导出产物包含底图 + 点位 + 走线 + 比例尺 + 图例（AC-6.2）；
  6. 底图为图片/PDF 时点"导出 DXF" → 出现 AC-7.4 告知文案，产物仍含全部 `SS-*` 矢量层。
